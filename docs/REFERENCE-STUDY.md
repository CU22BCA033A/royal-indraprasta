# Reference study

## Limits of this study (read first)

The brief asks for screenshots and measurements of about ten live reference sites. That was **not possible** in the build environment: outbound browsing is restricted to an allowlist, and the official sites of MTR, A2B, Saravana Bhavan, Vidyarthi Bhavan, Taj, ITC and Lemon Tree were all blocked, as were the brand's own domains. Awwwards listing pages loaded but give names only, without designs or categories.

So this file is split in two:

1. **Verified today:** what could actually be read.
2. **Prior knowledge, not re-verified:** patterns of the category from general familiarity, clearly labelled. No screenshots, scores or code details are claimed for these sites.

The owner or developer should spend an hour with the sites in section 2 in a normal browser before launch and correct anything here.

## 2. Category patterns (prior knowledge, not re-verified)

**Multi-branch South Indian chains** (MTR, A2B, Saravana Bhavan, Kamat):

- Do well: an outlet finder that lists every branch with address and phone; signature dishes named plainly; a heritage line on the home page.
- Do badly: heavy carousels, menus as images, outlet lists as long unstyled tables, slow pages on mobile, pop-ups for app downloads, the same stock thali photo on every page.

**Indian hotel brands** (Taj, ITC, Lemon Tree):

- Do well: a clear "book a room" or "enquire" path per property; property pages with consistent templates (location, facilities, contact).
- Do badly: autoplay video heroes, heavy JavaScript, generic luxury copy that could describe any property.

**Editorial restaurant sites** recognised by award galleries:

- Do well: one dominant typographic or photographic idea per screen; generous scale contrast; menus set like print with prices in a column; restrained colour (one strong colour plus neutrals); the address and hours treated as design, not small print.
- Do badly: scroll-jacking, WebGL, hidden navigation, low-contrast text over images.

## 3. What this means for us

Learn: a branch index and identical per-branch pages; signature dishes over long lists; address and hours set large; one strong colour used as a field, not an accent; print-menu typography.

Avoid: carousels, menus as images, stock food photos, autoplay, app prompts, luxury clichés, scroll effects.
